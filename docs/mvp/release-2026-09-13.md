## Installed app and reinstall

The installed app is **ClearAF**, bundle `com.aryansachdev.ClearAF`, configuration **Release**, on the paired iPhone 16 Pro. It connects to the hosted HTTPS API and Supabase. Internet is required; the Mac's local backend does not need to run. ClearAF Dev is a separate local-development app. Updates use refresh, not live push; photos must be uploaded/shared to appear in the portal.

The embedded provisioning profile expires **September 20, 2026 at 20:21:18 UTC (3:21 p.m. America/Chicago)**. Reinstall with renewed signing before a later demo. This is direct development signing of a Release configuration, not TestFlight or App Store distribution.

To reinstall, connect/unlock the paired phone, use the authorized Xcode signing account, inspect the current device identifier and build the intended reviewed source:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun devicectl list devices
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project ClearAF.xcodeproj -scheme ClearAF -configuration Release \
  -destination 'id=<current-device-id>' -derivedDataPath <private-build-directory> \
  -allowProvisioningUpdates build
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun devicectl device install app \
  --device <current-device-id> <private-build-directory>/Build/Products/Release-iphoneos/ClearAF.app
```

Inspect the newly embedded provisioning profile for its actual expiry; do not assume the old date extends automatically. Install over the same bundle without deleting its data. Keep signing artifacts outside Git. Apple authentication/trust prompts require the user's participation when shown.
