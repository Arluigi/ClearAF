Moving machines

  1. Keep a secure copy of the old laptop’s private ClearAF files. They include material that is deliberately outside GitHub.
  2. Install Xcode with one iPhone Simulator, Node 24, Git and a Docker-compatible runtime.
  3. Sign in to GitHub, Vercel, Supabase and the Apple development account as needed. These credentials are not part of the code.
  4. Clone the repository and use codex/account-reliability. Follow the setup guide to recreate the local test environment.

Before release

This phase does not deploy production changes. Hosted email callbacks and an authorized hosted test account still need release verification. Your cousin must decide clinical retention and account-removal policy; the app currently states that removal is unavailable.
